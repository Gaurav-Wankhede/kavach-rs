① Hook Lifecycle — how a turn is governed

Claude Code / Cursor / Codex fire hook events; each routes through kavach gates <event> into kavach-engine. The engine reads/writes the SurrealDB store via kavach-rpc and emits injected awareness (SessionStart) or block/ask/advisory verdicts (PreWrite/Bash/Stop).

④ Data & Awareness Flow — single writer, many readers

All mutation funnels through the single-writer RPC daemon (no client races). The SurrealDB store holds the project memory: kanban cards, decisions, the anti_pattern graph (mistakes + loopholes umbrella), concepts, and gate-config directives. SessionStart reads this back as injected awareness — the cure for amnesia.
